# Pomodoro-Template

ポモドーロ・テクニックを使ったタスク管理テンプレート

## 概要

このテンプレートは、ポモドーロ・テクニックに基づいたタスク管理システムを提供します。タスクの予定と実績をポモドーロ単位で記録し、効率的な時間管理を実現します。

## ファイル構成

- **Stock.md**: 全タスクのバックログ（時間軸で管理）
- **Daily/YYYY-MM-DD.md**: その日の実行ログ
- **.vscode/markdown.json**: VS Code用のユーザースニペット

## タスク記述構文

### 基本書式
```
- [ ] タスク名 [p][p] {due:YYYY-MM-DD}
```

### ポモドーロ記号
- `p` (小文字): 予定（planned）- タスクに必要と見積もられるポモドーロ数
- `P` (大文字): 実績（Performed）- 実際に消費したポモドーロ数

### 締切タグ
- `{due:YYYY-MM-DD}`: 具体的な締切日
- `{due:NONE}`: 締切なし

### 例
```markdown
- [ ] レポート作成 [p][p][p] {due:2024-01-20}
- [ ] コードレビュー [p] {due:2024-01-15}
- [ ] 技術調査 [p][p] {due:NONE}
```

## Stock.mdの使い方

Stock.mdは4つのカテゴリでタスクを管理します：

1. **Daily**: 毎日実行するタスク
2. **Weekly**: 毎週実行するタスク
3. **Monthly**: 毎月実行するタスク
4. **Someday**: いつか実行するタスク

## Daily/YYYY-MM-DD.mdの使い方

毎日新しいファイルを作成し、以下のセクションで構成します：

1. **本日の予定**: その日に実行予定のタスク
2. **実行ログ**: セッションごとの実績記録
3. **振り返り**: 完了タスク数、学び、改善点
4. **明日の予定**: 次の日の計画

### セッションの記録方法

```markdown
### 09:00 - セッション1
- [x] タスク名 [P][P] {due:2024-01-15}
  - 実施内容のメモ
  - 気づいたこと
```

## VS Codeスニペットの使い方

### スニペットの種類

| プレフィックス | 説明 | 出力例 |
|--------------|------|--------|
| `task1` | 1ポモドーロタスク | `- [ ] タスク名 [p] {due:YYYY-MM-DD}` |
| `task2` | 2ポモドーロタスク | `- [ ] タスク名 [p][p] {due:YYYY-MM-DD}` |
| `task3` | 3ポモドーロタスク | `- [ ] タスク名 [p][p][p] {due:YYYY-MM-DD}` |
| `task4` | 4ポモドーロタスク | `- [ ] タスク名 [p][p][p][p] {due:YYYY-MM-DD}` |
| `taskn` | 締切なしタスク | `- [ ] タスク名 [p] {due:NONE}` |
| `taskdone` | 完了タスク | `- [x] タスク名 [P] {due:YYYY-MM-DD}` |
| `dailylog` | デイリーログテンプレート | フルテンプレートを展開 |
| `session` | セッションログ | セッション記録を展開 |

### 使用方法

1. VS Codeでマークダウンファイルを開く
2. 上記のプレフィックスを入力
3. Tabキーを押してスニペットを展開
4. Tabキーで各プレースホルダーを移動しながら入力

## ワークフロー例

### 1. 週の始まり
Stock.mdのWeeklyセクションから今週のタスクを確認

### 2. 毎朝
1. 新しいDaily/YYYY-MM-DD.mdファイルを作成（`dailylog`スニペット使用）
2. Stock.mdから今日実行するタスクを選択
3. 「本日の予定」セクションに記入

### 3. ポモドーロ実行中
1. セッション開始時に時間を記録
2. 25分作業 + 5分休憩
3. セッション終了時に実績を記録（`session`スニペット使用）

### 4. 1日の終わり
1. 「振り返り」セクションを記入
2. 「明日の予定」セクションを記入
3. 未完了タスクをStock.mdに戻す（必要に応じて）
